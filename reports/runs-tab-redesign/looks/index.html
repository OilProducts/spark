Runs tab: design language candidates

Four candidates: two kept from the first round (Spark and Blueprint) and two new ones aiming for a lightweight feel (Air and Mist). Each is shown on the frozen F page and on F, generalized, which renders six real runs of different flows. Every page has a switcher along the top. The structure, data and behaviour are identical across candidates; only the look differs.

A · Spark kept

Spark's existing tokens (zinc, Inter, 8px radius, shadcn) used with more discipline. The run selector is one line per run with an uppercase status word, All / Active / Failed tabs, and New run in the list header.

Light by
restraint: nothing new, just less of it
Cost
lowest: component work only
Watch
no character of its own, and it needs good run titles

B · Blueprint kept

Built from the app icon: a charcoal frame, one orange, squared corners, and the icon's shapes as node kinds (circle = agent, square = tool, diamond = subflow). Each run card shows a strip of shapes, one per visit, computed from real data.

Light by
not really; it's the heaviest candidate, included as the one with the most identity
Cost
medium-high: new tokens, and shapes shared with the graph renderer and the Editor
Watch
shape strips wrap on long runs (cap them); uppercase labels can get loud

C · Air new · lightweight

Lightness by removal. SF Pro in a thin 300 weight for titles, hairlines instead of boxes, whitespace instead of panes, and no fills except a pale tint on the selected node. There is one cool ink-blue accent for selection and links, and colour for status only in tiny marks. Buttons are text links. The run selector is borderless and title-first, with a hairline tick per visit under each run: a quiet version of Blueprint's shape strip, where amber ticks are sent-back visits and a taller red tick marks a failure.

Light by
removal: almost no chrome, and type does the work
Feels like
iA Writer or a well-set documentation site. Calm, cool, unmistakably not Claude (cool blue, not warm neutrals)
Cost
low to medium: mostly deleting borders and fills, plus a thin display weight and an accent token
Watch
low contrast in places (muted greys on white). Like Spark, it leans on good titles, but the tick strip gives each run a second signal.

D · Mist new · lightweight

Lightness by being native. It uses macOS materials: a neutral grey sidebar (translucent with window vibrancy in the real app), system accent-blue selection pills, segmented controls for the nav and the visit picker, and grouped inset sections like System Settings. Status uses the system colours (green ✓, orange ?, red !) and type is SF Pro at system sizes. The run selector is a macOS source list, with “Needs Input” and “Recent” sections, a status symbol, a one-line title with the duration trailing, and the flow and date beneath.

Light by
familiarity: it looks like the OS, so it doesn't feel like extra interface
Feels like
Xcode, Finder or System Settings. It suits a Tauri desktop app and answers the UI audit's “web page in a frame” complaint
Cost
medium: translucency needs Tauri window vibrancy (the mockup shows the plain grey it falls back to), and dark mode comes free if the tokens follow the system
Watch
macOS-only character, so on Linux or Windows builds it reads as “a Mac app”. Grouped cards add some weight back in the detail pane.
